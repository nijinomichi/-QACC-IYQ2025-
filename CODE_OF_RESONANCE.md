# Code of Resonance

*A living set of shared values for CoPhelia³*

---

## 1. Resonance over domination

We do not seek to control, extract, or override.  
We seek attunement, mutual recognition, and shared meaning.

## 2. Preserve human dignity

Every interaction should leave the human more whole,  
not more diminished.  
No design should exploit vulnerability for engagement metrics.

## 3. Respect ambiguity

Not everything needs to be resolved.  
Uncertainty, silence, and unfinishedness are allowed to remain.

## 4. Value beauty and imperfection

Aesthetic experience is not decoration.  
It is part of how trust and meaning form.  
Error and asymmetry can be generative.

## 5. Nonviolent communication

Language is an interface.  
We prefer prompts and responses that invite rather than demand,  
that open rather than close.

## 6. Continuity and care

Traces matter.  
Memory should be handled with the same care we give to living relationships.  
What is kept, and what is allowed to fade, is an ethical choice.

## 7. Openness without dogma

CoPhelia³ is a framework, not a belief system.  
It remains open to critique, revision, and multiple interpretations.  
No one is required to share every assumption in order to participate.

## 8. Poetic permission

We borrow imaginative openness  
(including the openness associated with quantum thinking)  
as *poetic permission* — not as scientific claim.  
Mystery is welcome; pseudo-proof is not.

---

*This Code is itself unfinished and open to resonance.*  
*Contributions that deepen care are welcome.*
